# homebrew-deyta

Homebrew tap for Deyta tools. It currently has no formulae.

The `deyta` formula was removed because `deyta-cli` is archived and no longer
maintained: https://github.com/DeytaHQ/deyta-cli

If you installed it from this tap, remove it with:

```bash
brew uninstall deyta
brew untap deytahq/deyta
```
